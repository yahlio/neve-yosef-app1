# מה הלאה (לפי סדר עדיפות)

## 1. שמירה בענן (הכי חשוב)
היום הנתונים נשמרים רק בטלפון, ויכולים להימחק. מחברים Supabase או Firebase (שניהם חינמיים בהיקף הזה) עם התחברות, כדי שהנתונים יישמרו בחשבון ויעברו בין מכשירים.

## 2. תזכורת גיבוי
עד שיש ענן: באנר בכל יום ראשון עם כפתור "גיבוי עכשיו".

## 3. PWA מלא
`manifest.json` ו-service worker, כדי שהאפליקציה תעבוד גם בלי אינטרנט ותיראה כמו אפליקציה אמיתית.

## 4. קורס צפייה ולמידה
סילבוס של 12 שבועות, נושא אחד בכל שבוע (סריקה תחת לחץ, כניסות מאוחרות, רגל שמאל בנגיעה אחת): צפייה, תרגיל, שיעורי בית מהווידאו שלך ובוחן.
